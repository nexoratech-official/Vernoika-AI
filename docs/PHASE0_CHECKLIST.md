# Phase 0 — Execution Checklist

## A. Product definition
- [ ] Confirm the product brief and Alpha scope.
- [ ] Define the first target user and top three use cases.
- [ ] Write acceptance criteria for each Alpha feature.
- [ ] Create a list of non-goals and safety boundaries.

## B. Brand foundation
- [ ] Check domain availability through a registrar.
- [ ] Search relevant trademark databases and consult a qualified professional before filing.
- [ ] Create original logo concepts.
- [ ] Finalize colors, typography, icon style, and voice.
- [ ] Create desktop and mobile logo lockups.

## C. UX design
- [ ] Draw dashboard wireframe.
- [ ] Draw chat workspace.
- [ ] Draw sign-in and onboarding.
- [ ] Draw settings, privacy, and permissions.
- [ ] Define loading, empty, error, and offline states.
- [ ] Test the design at mobile, tablet, and desktop widths.

## D. Engineering foundation
- [ ] Create a private Git repository named `vornokia`.
- [ ] Add README and docs.
- [ ] Create the Next.js web scaffold.
- [ ] Add formatting, linting, and type checking.
- [ ] Add `.env.example`; keep real secrets in local environment variables.
- [ ] Add a basic CI workflow.
- [ ] Create database schema and migrations before storing user data.

## E. Security foundation
- [ ] Define data retention and deletion behavior.
- [ ] Define account and session security.
- [ ] Keep secrets server-side.
- [ ] Define authorization checks and rate limits.
- [ ] Define audit events for future tool actions.
- [ ] Require confirmation for consequential external actions.

## Phase 0 exit criteria
Phase 0 is complete when the product brief, brand draft, wireframes, architecture, repository, security baseline, and Alpha acceptance criteria are reviewed and committed. Do not call the product launched at this point.
