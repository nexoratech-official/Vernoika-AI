# Vornokia AI — Product Brief

## Product definition
Vornokia AI is an independent AI ecosystem intended to help people understand information, plan work, use approved tools, coordinate specialized agents, and interact with connected devices through permissioned interfaces.

## Brand hierarchy
- Vornokia AI: flagship, more capable AI ecosystem.
- Nexora AI: smaller, less powerful counterpart with its own product identity.
- Nexora is not Vornokia's parent.

## Product promise
One intelligence across many platforms, with user control, transparent actions, and verifiable results.

## Initial target user
A technically curious individual who wants one assistant for conversations, research, personal productivity, and eventually authorized computer and device workflows.

## Alpha scope (first useful release)
1. Account sign-in and sign-out.
2. Responsive web dashboard.
3. Text chat with one external AI provider through a server-side adapter.
4. Conversation history.
5. Basic user preferences.
6. Clear usage and error states.
7. A permission and privacy settings page.
8. Basic logging and operational monitoring.

## Explicitly out of scope for Alpha
- Unrestricted computer control.
- Background surveillance or always-on recording.
- Autonomous payments, purchases, or account changes.
- Smart-lock or safety-critical device control.
- Public agent marketplace.
- Training a foundation model from scratch.
- Native mobile and desktop applications.

## Core user journey
1. User signs in.
2. User opens the Vornokia workspace.
3. User starts a conversation.
4. Server authenticates the request and checks usage limits.
5. Model gateway routes to a configured provider.
6. Response is streamed or returned.
7. Conversation is stored according to user settings.
8. User can review, export, or delete their data.

## Product principles
- User control before autonomy.
- Explicit permissions for external actions.
- Minimize stored personal data.
- Provider independence.
- Accessibility and responsive design.
- Never claim an action succeeded without verification.
