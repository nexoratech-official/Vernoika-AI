# Vornokia Brand System — Draft 0.1

## Positioning
An independent AI ecosystem and personal intelligence platform.

## Tagline
ONE INTELLIGENCE. EVERY PLATFORM.

## Brand personality
Intelligent, composed, capable, precise, transparent, and calm. Avoid exaggerated claims of consciousness or unrestricted autonomy.

## Visual direction
- Primary background: midnight navy `#071322`
- Elevated surface: `#10243A`
- Primary accent: electric cyan `#42C8F5`
- Secondary accent: blue `#477BFF`
- Main text: `#F4F8FC`
- Muted text: `#A8B8C9`
- Borders: `#243A50`

## Typography
Use a modern sans-serif such as Geist or Inter. Use a clear hierarchy, readable body sizes, and restrained letter spacing.

## Interface rules
- Dark mode as the initial signature theme; light mode can follow.
- Use cyan for active states and meaningful highlights, not every element.
- Motion should be subtle and respect reduced-motion preferences.
- Make keyboard navigation and visible focus states first-class.
- Never use visual status alone; include text labels for errors and permissions.

## Logo direction
Create an original abstract mark suggesting connected intelligence or a neural pathway. Avoid copying J.A.R.V.I.S., Marvel, Nokia, or other existing marks. Complete trademark and domain checks before public launch.
