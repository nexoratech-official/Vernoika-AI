# Vornokia Roadmap

Timelines are planning estimates, not promises. Re-estimate after each milestone.

## Phase 0 — Foundation
Product brief, brand, wireframes, architecture, repository, security baseline, acceptance criteria.

## Phase 1 — Vornokia Alpha web
Authentication, responsive dashboard, chat, server-side model gateway, conversation history, preferences, basic monitoring.

## Phase 2 — Personalization
User-controlled memory, retrieval, voice input/output, data export and deletion.

## Phase 3 — Vornokia Agents
Prime coordinator, bounded specialist agents, task state, tool registry, approvals, execution verification.

## Phase 4 — Desktop
Start with a permissioned Windows companion; add macOS and Linux after validating the architecture.

## Phase 5 — Mobile
Android and iOS clients using the shared API and identity system.

## Phase 6 — Connect
Home Assistant and selected device integrations. Use explicit device permissions and confirmations for consequential actions.

## Phase 7 — Developer
API keys, SDK, documentation, webhooks, quotas, developer console, and versioning.

## Phase 8 — Ecosystem
Reviewed third-party agents and extensions, marketplace operations, billing, and revenue share.

## Phase 9 — Model independence
Evaluate open-weight models, self-host selected workloads, optimize inference, and research proprietary models only when justified.

## Release gates
Each phase requires security review, usability testing, measurable acceptance criteria, and a rollback plan before public release.
